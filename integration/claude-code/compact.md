## superpowers-audit after compaction

Compaction drops hook-added context. If you are mid-way through `superpowers:brainstorming` or
`superpowers:writing-plans`, use the Skill tool to reload that skill once; its audit stage returns
with it. Then continue from where you were; do not restart that skill's checklist. Before
dispatching or continuing an audit, reload `superpowers-audit:superpowers-audit` with the Skill tool
for its dispatch and configuration context. Follow the shared skill's interruption rules:
recover the active question audit and any paused enclosing audit, retaining each
target, session, model, and round count separately, together with unresolved findings.
Continue the active audit's own session; never substitute the parent's or reset a budget.
If identity or progress is missing, recover or ask before dispatch; do not resend a delivered round.
